# Serpstack
> Serpstack is a real-time search engine results page (SERP) scraping REST API, used by startups, SMBs, and large brands to power rank tracking, SEO and SERP monitoring, competitor and ad research, keyword tools, and market intelligence. A single HTTP GET returns a fully parsed Google results page as structured JSON or CSV, covering organic results, sponsored ads, local map packs and local results, knowledge graph entries, answer boxes and related questions, related searches, rich snippets and sitelinks, image, video, news and shopping results, and pagination. The service runs on a global proxy network with browser clusters and built-in CAPTCHA handling, so callers never manage IPs or solve challenges themselves, and the infrastructure is queueless — requests are processed in milliseconds rather than batched. Queries can be tailored by location down to city level, language, country, Google domain, device (desktop, tablet, or mobile), safe-search, result count, and page. Data streams are protected with 256-bit SSL, and average uptime is near 99.9%. Serpstack is part of the APILayer suite (one account, one API key, one dashboard across the APILayer product family).
A free API key is available at https://serpstack.com/signup/free — the Free Plan includes 100 searches per month with global locations, the proxy network, all search types, and HTTPS, returning JSON only, restricted to non-commercial use and without support; paid plans add commercial-use rights, CSV output, no rate limit, and standard support. Paid tiers are Basic ($29.99/month, 5,000 searches), Business ($99.99/month, 20,000 searches), and Business Pro ($199.99/month, 50,000 searches), with custom Enterprise pricing including a custom SLA, and up to 15% off on annual billing. Authentication is a 32-character access key appended as the access_key query parameter. The base URL is api.serpstack.com. A single search is one HTTP GET request: api.serpstack.com/search?access_key=YOUR_KEY&query=mcdonalds. The main endpoint is Search (GET /search), which accepts query plus optional engine (Google by default), type (web, images, videos, news, or shopping), device, location, google_domain, gl (country) and hl (language), safe, num, page, auto_location, and output (JSON or CSV); a companion Locations endpoint resolves the location identifiers used for geo-specific searches. Errors are returned as a JSON object with a numeric code, type, and info message, and failed requests are not counted against the monthly quota; usage notifications are sent at 75%, 90%, and 100% of the allowance, after which overage fees apply. Code examples are provided for multiple languages.

# Web Scraper
> Used by over 1 million people worldwide, Web Scraper provides scalable browser-based web scraping infrastructure for automated public web data extraction workflows.
Web Scraper combines visual scraper creation with cloud execution, scheduling, browser rendering, proxy management, and API automation, helping teams run large-scale scraping workflows without maintaining their own scraping infrastructure.

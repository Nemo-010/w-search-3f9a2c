# Spider
> Web crawling, scraping, and search API for AI agents and RAG pipelines.
> Any site to clean markdown or structured JSON. Rust engine, a headless
> Browser when a page needs it, proxy rotation, streaming.
- Website: https://spider.cloud
- API base: https://api.spider.cloud
- Browser: https://spider.cloud/browser/ (wss://browser.spider.cloud, up to 100 concurrent sessions)
- Proxy: https://spider.cloud/proxy-locations/ (http://proxy.spider.cloud, residential and ISP exits, rotated per request)
- Agent setup skill: https://spider.cloud/agent-skill/SKILL.md
- Full API reference: https://spider.cloud/llms-full.txt
- Docs: https://spider.cloud/docs/overview
- OpenAPI: https://spider.cloud/openapi.yaml
- MCP server: https://mcp.spider.cloud/mcp (setup: https://spider.cloud/mcp/connect)
- Pricing: https://spider.cloud/pricing ($1 per 10,000 credits; bandwidth at $1 per GB plus compute at $0.0001 per minute)
- Open source: https://github.com/spider-rs/spider (MIT)
- Support: support@spider.cloud, https://discord.spider.cloud
If you are an agent setting Spider up for a user, read
https://spider.cloud/agent-skill/SKILL.md. For the complete parameter

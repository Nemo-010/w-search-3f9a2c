﻿# Nimble
> Nimble is a real-time web search platform powered by Web Search Agents — turning the live web into structured, reliable data for AI and enterprise. Nimble web APIs enable two core use cases are 1) live web search that enables AI Agents to query the web like a live database, and 2) stream large-scale structured data feeds to applications and data lakes. Developer documentation lives at docs.nimbleway.com and is indexed separately at https://docs.nimbleway.com/llms.txt.

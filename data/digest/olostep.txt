# Olostep Docs
> Olostep: infrastructure for the Web's second user. Search, scraping and crawling API for AI.
## Documentation
### Get Started
- [Welcome to Olostep](https://docs.olostep.com/get-started/welcome.md): Olostep: Infrastructure for the Web's second user. The best search, scraping and crawling API for AI.
- [Authentication](https://docs.olostep.com/get-started/authentication.md): Authenticate to the Olostep search, scraping, and crawling API with API keys.
- [Olostep CLI](https://docs.olostep.com/sdks/cli.md): Command-line interface for scrape, search, map, crawl, answers, and batches — JSON output for scripts, CI, and AI agents
- [Pay-per-use (x402)](https://docs.olostep.com/x402.md): Pay-per-use API endpoints with stablecoins
### Features
- [Scrape](https://docs.olostep.com/features/scrapes.md): Turn any URL into LLM-ready Markdown, HTML, screenshots, PDFs, or structured JSON.
- [Crawl](https://docs.olostep.com/features/crawls.md): Crawl a URL and get the content from all subpages
- [Maps](https://docs.olostep.com/features/maps.md): Get all the URLs on a website.
- [Batch Endpoint](https://docs.olostep.com/features/batches.md): Best for large-scale, async data aggregation
- [Answers API](https://docs.olostep.com/features/answers.md): AI answers backed by live web search, scraping, and crawling — not a stale index.
- [Search API](https://docs.olostep.com/features/search.md): Search the web with natural language and get structured links — Olostep's AI search API.
- [Monitors](https://docs.olostep.com/features/monitors.md): Monitor pages on a schedule and send change alerts
- [Files](https://docs.olostep.com/features/files.md): Upload and manage JSON files for use as context in API requests
- [Schedules](https://docs.olostep.com/features/schedules.md): Schedule API calls to run automatically at specified times

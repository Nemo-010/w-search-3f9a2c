# You.com | Documentation
> Web Search, Answer, Contents, Research, and Finance Research APIs that give your AI app real-time web intelligence. Start with free credits.
## Instructions for AI Agents
- For clean Markdown of any page, append `.md` to the page URL
- Documentation index: https://you.com/docs/llms.txt (section indexes: append `/llms.txt` to any section URL)
- Search these docs: Docs MCP at https://you.com/docs/_mcp/server (`searchDocs`, no API key)
- Call live You.com APIs: Product MCP at https://api.you.com/mcp (keyless `?profile=free` exposes `you-search` and `you-discover`. Research and finance use `/mcp/research`, `/mcp/finance`, or `?tools=` on `/mcp`). To pick an API or integration path, call `you-discover` on that server instead of guessing
- OpenAPI: https://you.com/docs/openapi.json—auth header `X-API-Key`, env `YDC_API_KEY`
## Docs
- [Build agentic apps with real-time web intelligence.](https://you.com/docs/welcome.md): Web Search, Answer, Contents, Research, and Finance Research APIs that give your AI app real-time web intelligence. Start with free credits—no credit card required.
- [Choose the Right API](https://you.com/docs/choose-the-right-api.md): Match your job to the Web Search API, Contents API, Answer API, Research API, or Finance Research API. Compare latency, price, and output format in one table.
- [Quickstart](https://you.com/docs/quickstart.md): Get from zero to working API requests in minutes. Covers the Web Search API, Answer API, Contents API, Research API, Finance Research API, full page extraction, evaluation, and pricing—everything you need to evaluate You.com.
- [Build With Agents](https://you.com/docs/agents.md): Give any agent real-time web access: install a You.com MCP server, add the Agent Skills, or call the REST APIs directly.
- [MCP Server](https://you.com/docs/agents/mcp-server.md): Hosted MCP server for You.com web search, contents, research, and finance tools. One server, three POST endpoints. Enabled tools are the intersection of profile, allowlist, and path.
- [Docs MCP Server](https://you.com/docs/agents/docs-mcp-server.md): Give any MCP-enabled agent a searchDocs tool that searches all of You.com's developer documentation—API references, guides, and code examples—in real time. No API key.
- [Agent Skills](https://you.com/docs/agents/skills.md): Install You.com agent skills for current web search, URL content extraction, cited research, finance research, and integration discovery.
- [Plugins](https://you.com/docs/agents/plugins.md): Install the You.com skills through your platform's native plugin system—Claude Code, Cursor, Codex, Copilot CLI, Kimi Code, Grok Build, OpenCode, OpenClaw, Pi, Hermes, and DeepSeek Harness.
- [Agent Harnesses](https://you.com/docs/agents/agent-harnesses.md): Connect a coding agent to You.com. Web search, page fetch, and research cover docs, errors, and questions the model's training data does not.

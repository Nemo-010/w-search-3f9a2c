# NewsAPI.ai
> NewsAPI.ai is the news API of Event Registry: real-time and archive (since 2014) access to news, blog and press-release articles from 150,000+ publishers in 50+ languages. Every article is enriched with entities (concepts linked to Wikipedia), categories, sentiment, locations and duplicate information; related articles are clustered into events, and Signal Types classify 136+ kinds of real-world developments (mergers, layoffs, protests, wildfires, ...) at the sentence level. Access is via a REST API (JSON over GET or POST), Python and Node.js SDKs, and an MCP server.
Key facts for using the API:
- Authentication: every request carries an `apiKey` parameter. Registration at https://newsapi.ai/register is free and includes 2,000 tokens (no credit card); the key is shown on https://newsapi.ai/dashboard.
- Base URL: `https://eventregistry.org/api/v1/...` (the same paths also work on `https://newsapi.ai`). Text-analytics endpoints live on `https://analytics.eventregistry.org/api/v1/...`. Send `POST` requests with a JSON body (`Content-Type: application/json`); `GET` with query parameters also works for simple calls.
- Most-used endpoints: `/api/v1/article/getArticles` (search articles), `/api/v1/event/getEvents` (search events), `/api/v1/suggestConceptsFast` (turn a name into a concept URI). Prefer concept URIs (e.g. `http://en.wikipedia.org/wiki/Tesla,_Inc.`) over keywords: they match an entity in every language.
- Costs: searching recent data (last 30 days) costs 1 token per article search and 5 per event search; searching the archive costs 5 / 20 tokens per searched year. A search returns at most 100 articles or 50 events per page.
- Limits: at most 5 simultaneous requests per user (HTTP 429 otherwise); make requests sequentially. HTTP 401/403 mean the token limit was reached or the key/IP is disabled.
- Complex boolean queries use the `query` parameter with a MongoDB-like JSON (`$query` with `$and` / `$or` / `$not`, plus an optional `$filter`); it cannot be combined with the simple `keyword`, `conceptUri`, ... parameters in the same request.

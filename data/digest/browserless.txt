# Browserless
> Browserless is a cloud browser automation platform. Connect Puppeteer, Playwright, or Selenium to managed headless browsers over WebSocket, or use BrowserQL, REST APIs, and MCP for scraping, screenshots, PDFs, and AI-driven browsing.
For full technical documentation, see [docs.browserless.io](https://docs.browserless.io/) or the [detailed llms.txt](https://docs.browserless.io/llms.txt).
## Quick Start
- [BaaS Quick Start](https://docs.browserless.io/baas/quick-start): connect existing Puppeteer or Playwright code to Browserless in minutes
- [BrowserQL Quick Start](https://docs.browserless.io/browserql/getting-started): first BrowserQL request and workflow
- [API Comparison](https://docs.browserless.io/overview/comparison): choose between BrowserQL, BaaS, and REST APIs
- [Connection URLs](https://docs.browserless.io/overview/connection-urls): shared-fleet and private-fleet connection patterns
## APIs
- [Browsers as a Service (BaaS)](https://docs.browserless.io/baas/start): remote browser automation for existing Puppeteer, Playwright, or Selenium code
- [BrowserQL](https://docs.browserless.io/browserql/start): GraphQL-based browser automation with stealth, conditional logic, and structured extraction
- [REST APIs](https://docs.browserless.io/rest-apis/intro): one-shot HTTP endpoints for screenshots, PDFs, scraping, search, and more
- [OpenAPI Reference](https://docs.browserless.io/open-api): full REST API specification
## AI and MCP
- [Browserless MCP Server](https://docs.browserless.io/mcp/browserless-mcp-server): Model Context Protocol server with smart scrape, function, download, export, search, map, performance, and crawl tools
- [AI Integrations](https://docs.browserless.io/ai-integrations/start): Browser Use, Stagehand, LangChain, Claude Code, n8n, Make, Zapier, and more

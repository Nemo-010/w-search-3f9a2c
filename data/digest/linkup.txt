# Linkup
> The production-grade Web Search API for AI. Used by McKinsey, SNCF, Cohere, Legora, Polymarket, and Artisan AI. #1 on OpenAI's SimpleQA.
Linkup is a web search API that gives AI applications and agents real-time, grounded access to the web through a single API call, or deployed inside your own cloud for enterprise needs. Prefer the Documentation links below (markdown) for API usage; use Key pages for product, pricing, and proof.

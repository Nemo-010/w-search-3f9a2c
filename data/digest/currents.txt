# Currents News API
> Real-time news API with a large historical article index, broad monitored source catalog, and 20+ languages. Developer-friendly JSON with monitored production reliability and a free tier.
## Overview
Currents News API provides structured news data via REST endpoints. New articles are indexed daily from a source directory of 12,000+ source entries assigned to 168 country designations.
## Key endpoints
- [Latest News](https://currentsapi.services/en/docs/latest_news) — breaking news with language/country/category filters
- [Search](https://currentsapi.services/en/docs/search) — archive keyword search across indexed articles
- [OpenAPI Specification](https://currentsapi.services/json/swagger.json) — machine-readable API reference including available language/region/category endpoints

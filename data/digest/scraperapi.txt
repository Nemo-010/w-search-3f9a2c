# ScraperAPI
> ScraperAPI is a web scraping API that helps developers and data teams collect data from any public website at scale, handling proxy rotation, JavaScript rendering, and CAPTCHA/anti-bot bypass automatically behind a single REST call. Structured-data endpoints return clean JSON for high-demand targets (Amazon, Google, Walmart). Native MCP server (22 tools) and Claude Code Agent Skills plugin for AI-agent workflows. LangChain, LlamaIndex, n8n, and Zapier integrations. Founded 2018. Part of the saas.group portfolio. Acquired Traject Data (2026). 10,000+ customers including Deloitte, Sony, Alibaba. 11B+ requests/30 days. 40M+ IP pool. 99.9% uptime. Pricing: Hobby $49/mo (100K credits) - Startup $149/mo (1M credits) - Business $299/mo (3M credits) - Scaling $475/mo (5M credits, Most Popular, PAYG) - Professional $975/mo (10.5M credits) - Advanced $1,975/mo (21.5M credits) - Enterprise custom. 7-day free trial, 5,000 credits, no credit card required. Credit multipliers: Amazon 5x, Google/Bing 25x, LinkedIn 30x; +10 credits for anti-bot bypass.

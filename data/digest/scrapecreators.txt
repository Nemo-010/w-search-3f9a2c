# Scrape Creators
> Scrape Creators provides APIs for scraping public creator and social media data from TikTok, Instagram, YouTube, Twitter/X, Facebook, Reddit, LinkedIn, and other platforms.
This file is a compact product-level guide for AI tools. For endpoint-level API details, use the docs LLM files below.

## API Basics
Base API URL: `https://api.scrapecreators.com`
Authentication: pass your API key in the `x-api-key` header.
Use the docs links above before writing integration code. The docs `llms-full.txt` file is the best source for AI coding tools because it includes endpoint paths, params, and sample responses in one Markdown file.

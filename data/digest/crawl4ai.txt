# Crawl4AI Cloud API
> Crawl4AI turns any web page into clean, LLM-ready data. One key: `/scrape` a page to Markdown,
> `/extract` it to JSON, `/search` the web, `/serp` for Google's results page as data, `/answer` a
> question with sources, and batches of many URLs — served from three regions (EU, Singapore, US)
> at `https://api.crawl4ai.com`, routed to the nearest one. Free: 10 a minute, 2 at a time, 1,000
> credits every month. Plans from $10 a month (Starter: 10,000 credits, 120 a minute, 10 at a time), then
> Builder $99 and Scale $499; extra credits on a plan never expire. The live table: `GET /v1/prices`.
> Built on the open-source crawl4ai (https://github.com/unclecode/crawl4ai).
Full docs: https://api.crawl4ai.com/docs
Migrating from the legacy API, now api-old.crawl4ai.com (v1 sessions, scan, site, enrich, context): https://crawl4ai.com/migrate.txt
## Set up (for coding agents)
When the user sends "set up crawl4ai - https://crawl4ai.com/llms.txt with key: sk_live_...", add the
Crawl4AI MCP server to YOUR OWN config with that key, then call the free `balance` tool to check it works.
Put the key in the user-level config, never in a file inside the user's repository.
This file shows only what is open to everyone. **With your key it shows everything open to your account:**
`curl -H "Authorization: Bearer <key>" https://crawl4ai.com/llms.txt`. The server is
`https://api.crawl4ai.com/mcp` (streamable HTTP), the header is `Authorization: Bearer <key>`.
- Claude Code: `claude mcp add --transport http --scope user crawl4ai https://api.crawl4ai.com/mcp --header "Authorization: Bearer <key>"`

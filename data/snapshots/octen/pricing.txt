# Pricing

> Prices for Octen's APIs and models, and how billing works.

<p style={{ fontSize: "0.8rem", opacity: 0.6 }}>For AI agents: <a href="https://docs.octen.ai/overview/pricing.md">docs.octen.ai/overview/pricing.md</a></p>

## Overview

Our pricing combines a **monthly QPS Plan subscription** with **pay-as-you-go API billing**:

<Steps>
  <Step title="Subscribe to a QPS Plan">
    New accounts start on the Free plan; adding credits unlocks Base at no monthly cost.
  </Step>

  <Step title="Top up your balance">
    API charges are deducted from your balance in real time.
  </Step>

  <Step title="Pay as you go">
    Charges are based on actual resource consumption (API calls, tokens).
  </Step>
</Steps>

<Tip>All new users receive **\$5 in free balance** upon registration.</Tip>

## API Pricing

### Octen Fast

Octen Fast includes Broad Search, Web Search, Image Search, and Video Search.

| API | Search API Call | Full Content |
| - | - | - |
| Broad Search | <s>\$5</s> \$1 / 1k calls (80% off) | \$0.5 / 1k results |
| Web Search | <s>\$5</s> \$1 / 1k calls (80% off) | \$0.5 / 1k results |
| Image Search | \$2 / 1k calls | - |
| Video Search | \$5 / 1k calls | - |

A single Broad Search call may include multiple Search API calls.

For Broad Search and Web Search, the full content of the first 10 results per search is free; only additional results are billed.

### Octen Premier

Octen Premier includes News Search and Business Search.

| API | Search API Call | Full Content |
| - | - | - |
| News Search | \$3 / 1k calls | \$0.5 / 1k results |
| Business Search | \$5 / 1k calls | \$0.5 / 1k results |

The full content of the first 10 results per search is free; only additional results are billed.

### Extract

| Resource | Price (USD) |
| - | - |
| Standard mode | \$1 / 1k successful URLs |
| Advanced mode | \$2.5 / 1k successful URLs |

Each URL is billed at the mode it was processed in, including URLs handled by auto mode. Failed URLs are not billed.

## Application Pricing

### Answer and Multimodal Chat

Charges include Search fees (based on the number of search queries) and model usage fees (based on token consumption).

### Deep Research

Billed per request, based on the selected tier.

| Tier | Price (USD / request) |
| - | - |
| lite | \$0.2 |
| standard | \$1 |
| pro | \$2.5 |
| pro-visual | \$3 |

### Grounded Generation

Billed per generated output, based on the modality.

| Modality | Price (USD) |
| - | - |
| Image | \$0.25 / image |
| Video | \$1 / video |

 What is Currents News API? 
 Currents is a REST news API that delivers real-time and historical articles from a source directory spanning 168 countries and 20+ languages. Responses are clean JSON with metadata, descriptions, source URLs, available content fields, and filters for country, language, category, date range, and search keywords.
 How the News API Works 
 Send one HTTP request with your API key. The API returns a JSON list of articles. 
 1. Send a request 
 curl -G https://api.currentsapi.services/v1/latest-news \
 -H "Authorization: Bearer YOUR_API_KEY" \
 -d language=en -d page_size=3 
 /v1/latest-news returns the newest indexed articles. Filter them by language , country , and category . 
 /v1/search finds articles by keywords in a date window set by start_date and end_date . 
 A free key allows 250 requests per UTC day and up to 20 articles per request. Free searches have a 30-day lookback and a 7-day max date span per request.

 Simple Integration 
 Get started in minutes with our RESTful API 
 Python Example 
 import requests
API_KEY = "your-api-key"
URL = "https://api.currentsapi.services/v1/latest-news"
response = requests.get(
 URL,
 headers={"Authorization": API_KEY},
 params={"language": "en", "country": "US"}
)
data = response.json()
for article in data["news"]:
 print(article["title"]) 
 JavaScript Example 
 const API_KEY = 'your-api-key';
const URL = 'https://api.currentsapi.services/v1/search';
fetch(`${URL}?keywords=technology&language=en`, {
 headers: { 'Authorization': API_KEY }
})
 .then(res => res.json())
 .then(data => {
 data.news.forEach(article => {
 console.log(article.title);
 });
 }); 
 Works with any language that can make HTTP requests.

 Frequently Asked Questions 
 Is Currents News API free? 
 Yes! Currents offers a free tier with 250 daily requests. No credit card required to sign up. Simply register and start using the API immediately. 
 How much does Currents News API cost? 
 Pricing starts at $0 for the free tier (250 daily requests). Paid plans begin at $69/month for Builder (75K monthly requests), $150/month for Professional (300K monthly requests), and $300/month for Scale (600K monthly requests). 
 What countries does Currents News API cover? 
 Our source directory contains entries assigned to 168 country designations, including the United States, United Kingdom, India, China, Germany, France, Japan, Brazil, Australia, and many more. See the sources directory for per-country counts. 
 Does Currents News API offer real-time data? 
 Yes. Currents provides newly indexed news without an artificial plan delay. Observed freshness varies by publisher and source. 
 What programming languages can I use with Currents API? 
 Currents News API is a REST API that returns JSON, so you can use it with any programming language including Python, JavaScript, PHP, Ruby, Go, Java, Node.js, and more. 
 How fast is Currents API? 
 Response time varies by query, result size, and network path. Test representative requests with the endpoints and plan limits your application will use.

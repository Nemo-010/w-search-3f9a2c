How the daily tiers are calculated Daily volume discounts apply to every account — free, pay-as-you-go and enterprise alike. There is no plan to upgrade to and nothing to switch on: they reset each day and apply automatically. What does vary is the endpoint, because only some of them are tiered. On those, pricing is marginal — each bracket of requests is billed at that bracket's rate, the way income tax brackets work, so only the requests falling inside a range are billed at that range's price. Formula Cost = (requests in tier 1 × tier 1 price) + (requests in tier 2 × tier 2 price) + … for however many tiers your daily volume reaches Worked example 12,000 requests in one day on an endpoint with a base unit price of $0.0010 comes to $10.00. See dataset pricing Frequently asked questions How does pay-as-you-go work? You're charged $0.001 - $0.01 per API request depending on the endpoint. Volume discounts are calculated daily based on your total usage and applied automatically — no action needed. Do I need a credit card to start? No. New accounts get ~50 free requests to test every endpoint. Add credits when you're ready via Alipay, PayPal, or Crypto. What's the difference between volume tiers and RPS plans? Volume tiers reduce per-request cost based on daily usage. RPS plans increase your requests-per-second rate limit. They're independent — you can use both. Note that the rate limit is per endpoint, not per account: the default 10 RPS applies to each API path separately, so different endpoints can be called in parallel without competing for the same limit. Do repeat requests return cached data? No — every request returns fresh, real-time data and is billed independently, even with identical parameters. TikHub never serves cached data through the API. The cache_url in each successful response is a separate debugging and sharing aid: it re-opens that one response for 24 hours (free to access) so you can recover it when your code mishandled it (e.g. a wrong JSON path) or share it with a teammate. It is not a cheaper way to re-fetch the same content. How does enterprise pricing work? Enterprise accounts unlock permanent fee waivers, bonus credits, custom endpoints, and dedicated support. Minimum $3,000 one-time or $4,500 cumulative spend. Can I switch platforms or APIs anytime? Yes. Your API key works across all 16 platforms and 1,000+ endpoints. No separate subscriptions per platform. How are dataset orders processed? Select a dataset, choose format and date range, pay in full. Orders are auto-processed and you'll be notified when your download is ready. Ready to start? Get ~50 free requests — no credit card required.

Talk to sales AI Studio Alpha Natural-language endpoints on your existing key from $6/mo View AI Studio plans Frequently asked questions questions How does billing work? + Two line items per request: bandwidth ($1 per GB of pre-transformation content) and compute ($0.0001 per minute of CPU). Most pages land at a fraction of a cent. Failed requests cost $0. Does my balance expire? + No. Pay as you go has no subscription. Top up once and use the balance whenever you need it. Nothing resets monthly. Unlimited is a separate monthly plan you pick on the Unlimited tab. What if I need to top up more? + Top up any amount, any time. A single purchase of $500 or more earns an automatic bonus, and the top up form shows the exact percentage for each amount. You never have to negotiate for it. How does the Unlimited plan work? + Instead of paying per request, you buy concurrency: how many requests can be in flight at once. Pick any amount from 2 ($40/mo) up to 1,538 ($19,994/mo) and run unlimited requests through it for a flat monthly price. The price per concurrent request drops from $20 to $13 as you add concurrency. Each price band is billed on its own line, so one subscription shows several line items on the invoice. Above the self-serve maximum, talk to sales for a custom rate. Geo-targeting is not available on Unlimited yet. What happens when all my Unlimited concurrency is busy? + Requests beyond your concurrency limit get an immediate 429 with a Retry-After header. Spider queues nothing server-side and bills nothing extra. Retry or back off on your side, or add concurrency at any time. Any whole number works, not only the listed tiers. Are there multipliers for JS rendering or proxies? + None for JS rendering or standard proxies. JS rendering bills as compute, and proxy rotation comes with every request. Residential and ISP pools and AI extraction have their own prices, listed under Pricing details above. The only account-wide multiplier is the optional zero data retention setting, which bills requests at 2.5x credits. Enterprise plans include it at no extra charge. What are the rate limits? + Every account can make up to 10,000 core API requests per minute by default. Contact us if you need higher throughput. What if I get blocked? + Spider loads protected pages in its native browser, with rotating proxies and automatic retries. Heavily protected sites route to the cloud browser, which runs full sessions in a real browser engine. Does it respect robots.txt? + Yes. Spider follows robots.txt by default. You can turn it off per request. What formats can Spider return? + HTML, raw, plain text, and multiple markdown formats. API responses support JSON, JSONL, CSV, and XML. Per-endpoint costs are on the Scrape API and Crawl API pages, every parameter is in the API docs , and the AI agents use case shows a crawl wired in as an agent tool.

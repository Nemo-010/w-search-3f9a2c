Transparent pricing with no hidden fees. Start free, then add a plan whenever you want premium sources at a lower cost per credit. 
 ​ Plans 
 Everything runs on credits . $1 = 1 credit, and a single credit balance is shared across every API - Search, Answer, Contents, and DeepResearch. Higher plans simply give you more credits per dollar and unlock specialised and proprietary data sources. 
 Start free. New accounts get $10 in free credits ($20 with a work email), usable across every source so you can try the full catalog first. New organisations also get 50% off their first month for the first 24 hours after signup.

 All plans include web search and open academic sources (arXiv, PubMed). Plans then unlock specialised and proprietary families - and lower your cost per credit as you go. Each tier includes everything in the tiers below it.

 ​ Per-retrieval pricing (CPM) 
 Search and Answer price on CPM - cost per thousand retrievals. Set max_price to cap spend per query (sources priced above the cap are excluded, and the response returns a 206 partial-success warning). If you don’t set it, Valyu returns the best results regardless of source cost. 
 Data source type Per 1k retrievals What you get Open databases $0.50 Full-text arXiv, PubMed, clinical trials, and more Web search $1.50 Fresh, full-text web content Financial & market data $8.00 Real-time equities, crypto, market data Proprietary databases $30-50 Licensed journals, books, premium sources 
 Contents API charges $0.001 per successfully extracted URL, plus $0.001 if you add summarisation or structured extraction. Failed URLs are free. 
 Answer API bills search data (CPM rates above, capped by data_max_price ) plus $12 per million tokens for AI processing. 
 Worked examples Contents - 10 URLs, 2 failed: 8 × $0.001 = $0.008 . Answer - basic web query: ~10 results × $1.50/1k ($0.015) + ~2k tokens × $12/1M ($0.024) = ~$0.039 . Answer - academic with structured output: ~8 results × $8/1k ($0.064) + ~3k tokens × $12/1M ($0.036) = ~$0.10 . 
 ​ DeepResearch pricing 
 Fixed price per task - no extra search or content charges. DeepResearch plans, searches, verifies, and writes a cited report. 
 Mode Cost Typical runtime Fast $0.10 ~5 min Standard $0.50 ~10-20 min Heavy $2.50 up to ~90 min Max $15.00 up to ~180 min 
 Optional tools (off by default, enabled via tools ) add per-use surcharges: screenshots $0.05/URL (max 15), code execution $0.10/run, deliverables $0.10 each after the first, charts free. Failed tool calls aren’t charged, and PDF output isn’t a deliverable.
